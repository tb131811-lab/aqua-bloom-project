# 아쿠아블룸 AQUA BLOOM

한국어 열대어 쇼핑몰 메인 페이지. React + Vite로 만든 프런트엔드 데모입니다.

## 실행

Node.js 22.12 이상에서 이 폴더를 열고 다음을 실행하세요.

```sh
npm install
npm run dev
```

터미널에 표시되는 주소로 접속합니다. 배포용 파일 생성과 미리보기:

```sh
npm run build
npm run preview
```

이 작업 환경에서는 Windows의 상위 폴더 읽기 제한 때문에 개발 서버의 의존성 최적화가 차단될 수 있습니다. 이 경우 정상적으로 검증한 `npm run build`와 `npm run preview`를 사용하세요. 일반 로컬 환경에서는 `npm run dev`를 사용할 수 있습니다.

## 수정 위치

- `src/data.js`: 상품명, 특징, 종류, 정상가, 할인율, 이미지 경로, 쿠폰, 배송비. 판매가는 정상가와 할인율로 자동 계산합니다.
- `src/styles.css`: 색상, 여백, 반응형 화면, 모션 설정.
- `src/components/`: Header, Hero, Categories, ProductCard, Footer 컴포넌트.
- `src/App.jsx`: 검색, 필터, 장바구니, 입문 배너, 안내 모달.

아래 파일을 같은 이름으로 교체하면 됩니다. 다른 파일명은 `src/data.js`의 `images`에서 바꿉니다.

| 베타           | `public/images/betta.jpg`    | 코이 베타 사진                                         |

## 동작 범위

- 검색어 제출 시 상품명·종류·특징을 검색합니다.
- 상단 및 원형 카테고리로 상품을 필터링합니다. 등록되지 않은 수조·사료·관리용품에는 준비 중 상태가 표시됩니다.
- 상품의 + 버튼으로 장바구니에 담고, 모달에서 수량 증감·삭제·합계를 확인합니다.
- 장바구니는 현재 페이지 메모리에 보관되며 새로고침 시 초기화됩니다.
- 로그인·회원가입·쿠폰 발급·주문·결제는 실제 연동 없이 데모 안내를 표시합니다.
- 모든 가격·할인·쿠폰·배송·고객센터 정보는 시안용입니다. 실제 사업자 정보는 포함하지 않습니다.
- 데스크톱 상품 4열, 모바일 2열. 느린 확대·빛·기포·스크롤 전환은 `prefers-reduced-motion`에서 해제됩니다.

## 검증

프로덕션 빌드 성공. 1440px PC 및 390px 모바일에서 이미지 로딩, 가로 넘침 없음, 상품 4열/2열을 확인했습니다. 검색과 장바구니 추가·수량 증가·상품 합계 및 배송비 합산을 브라우저에서 확인했습니다.
